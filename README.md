# Artes de coleções do Nuvio em português do Brasil

83 conjuntos de artes originais para coleções: capa PNG 1280×720 (paisagem) ou 720×1080 (pôster), fundo JPG 1920×1080 e logo PNG transparente 1200×320.

As categorias incluem descoberta, serviços de streaming, gêneros, temas, estúdios, décadas, duração e países. Os nomes de marcas são usados apenas para identificar as categorias.

Os arquivos foram preparados para a configuração pessoal do Nuvio e publicados com autorização do titular desta conta. Este repositório contém apenas imagens e esta descrição; configurações, URLs de instalação e chaves não estão incluídas.

Use o endereço raw de cada imagem no campo correspondente do Nuvio: coverImageUrl (capa), heroBackdropUrl (fundo) e titleLogoUrl (logo).
